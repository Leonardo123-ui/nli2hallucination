# RAGTruth幻觉检测系统改进计划

## 📊 当前研究现状分析

### 1. 核心技术路线

```
RAGTruth数据集 (context + output)
            ↓
    RST Parser解析 (DM-RST模型)
            ↓
EDU提取 + 修辞关系构建 (20种关系类型)
            ↓
    BERT/ModernBERT编码 (1024维)
            ↓
DGL异构图构建 (节点=EDU, 边=修辞关系)
            ↓
    RGAT (关系感知图注意力)
            ↓
    多头注意力 + 图池化
            ↓
    分类器 (Focal Loss)
            ↓
        预测结果
```

### 3. 主要问题诊断

#### 问题1：严重的类别不平衡 ⚠️

**数据分布：**
```
训练集: 负样本(0) : 正样本(1) ≈ 3.4 : 1
测试集: 负样本(0) : 正样本(1) ≈ 3.4 : 1
```

**预测分布（Epoch 24）：**
```
Prediction: {0: 513, 1: 387}
Label:      {0: 696, 1: 204}
```

**影响分析：**
- 模型偏向预测多数类（无幻觉）
- 少数类（幻觉类）召回率不足
- 当前措施：Focal Loss (alpha=[0.8, 3.8], gamma=2.0)
- **效果评估：仍然不够，需要更激进的策略**

#### 问题2：图构建优化空间较大

**当前方法的局限性：**

1. **父节点特征聚合**
   - 现状：简单平均子节点embedding
   - 问题：丢失层次信息，无法区分重要子节点

2. **修辞关系建模**
   - 现状：20种关系统一处理
   - 问题：没有体现关系的重要性差异

3. **词汇链连接**
   - 现状：仅基于词汇相似度
   - 问题：语义信息不足

#### 问题3：LLM增强效果有限

**当前实现：**
```python
关键词提取 (top-10) → 节点权重 (0.5-1.0) → 特征乘法
```

**问题分析：**
- 关键词匹配过于粗糙
- LLM增强后F1提升 < 3%
- LLM调用开销大，收益有限

#### 问题4：模型过拟合倾向

**训练曲线分析：**
```
Train loss: 0.2212
Eval loss:  0.3815
Gap:        0.1603 (约73%)
```

## 🎯 Phase 1: 快速改进 (预计1-2周，目标提升 +5-8% F1)

### 1.1 调整Focal Loss参数 ⭐⭐⭐

**改进方案：**
```python
# 方案A: 更激进的类权重
FocalLoss(alpha=[0.5, 4.5], gamma=3.0, label_smoothing=0.05)

# 方案B: 组合损失
class CombinedLoss(nn.Module):
    def forward(self, logits, labels):
        focal = FocalLoss(alpha=[0.6, 4.0], gamma=2.5)
        bce = nn.CrossEntropyLoss(weight=[1.0, 3.4])
        return 0.7 * focal + 0.3 * bce
```

**预期提升：** +1-2% F1

### 1.2 实现动态阈值调优 ⭐⭐⭐

**实现方案：**
在验证集上寻找最优分类阈值，在0.3-0.7范围内网格搜索最大化macro F1的阈值。

**预期提升：** +2-3% F1

### 1.3 添加对比学习损失 ⭐⭐

**理论基础：**
- 无幻觉样本：premise和hypothesis应该语义一致
- 有幻觉样本：premise和hypothesis应该存在差异

**预期提升：** +1-2% F1

### 1.4 改进LLM融合方式（晚期融合）⭐⭐⭐

**改进思路：**
- 当前：早期融合，LLM信息可能被稀释
- 改进：晚期融合，LLM作为独立信号在分类层融合
- 提取结构化特征：[confidence, has_contradiction, num_critical_edus]

**预期提升：** +2-3% F1

## 🎯 Phase 2: 图结构优化 (预计2-3周，目标提升 +4-6% F1)

### 2.1 层次注意力聚合 ⭐⭐⭐

**问题：** 当前父节点特征是子节点的简单平均

**改进方案：**
使用注意力机制计算子节点权重，结合门控机制融合加权和与平均值。

**预期提升：** +2-3% F1

### 2.2 关系重要性学习 ⭐⭐⭐

**动机：** 不同修辞关系对幻觉检测的重要性不同
- 高相关：Contrast, Contradiction, Attribution
- 低相关：Joint, Same-Unit

**实现：**
- 可学习的关系重要性权重
- 关系嵌入
- 关系特定的图卷积

**预期提升：** +1-2% F1

### 2.3 跨图交互注意力 ⭐⭐⭐

**问题：** 当前premise和hypothesis只通过词汇链连接

**改进方案：**
- 双向跨图注意力（premise ↔ hypothesis）
- 门控融合机制
- 多层交互

**预期提升：** +2-3% F1

### 2.4 多尺度图池化 ⭐⭐

**实现：**
- 平均池化
- 最大池化
- 注意力池化
- Set2Set池化
- 融合所有池化结果

**预期提升：** +1% F1
