## 1️⃣ 第一阶段：数据预处理 (Data Preprocessing)

这是最枯燥但也最关键的一步。我们需要把字符级的“原始标注”转换成图神经网络能看懂的“节点标签”。

### 1.1 加载与清洗
* **文件位置：** /mnt/nlp/yuanmengying/nli2hallucination/data/ summary_data.json （注意要区分train和test）
* **输入：** `context` (原文), `output` (摘要), `hallucination_labels` (人工标注)。
* **操作：**
* 解析 `hallucination_labels`：这通常是一个列表，里面包含多个 `span`（起始/结束位置）。
* **统一化：** 忽略 `meta` 中的分类，只要 `label_type` 存在，就视为“幻觉”。


这一部分是整个流水线的**底层基石**。如果 EDU 划分不准或者标签对齐有偏差，后续的 GNN 学习就会因为噪声过大而无法收敛。

## 1.2 DMRST_Parser 深度解析与结构转换

DMRST 的输出是基于 Token 索引的“括号表达式”，而 GNN 需要的是“邻接矩阵（Edge Index）”。我们需要完成从**成分树 (Constituency)** 到 **依存图 (Dependency)** 的转换。

### A. 字符偏移量映射 (Character Offset Mapping)

由于 DMRST 使用 `xlm-roberta-base` 分词，而我们的幻觉标签是基于原始字符位置的，必须建立映射：
* 可以参考
```Python
/mnt/nlp/yuanmengying/nli2hallucination/data/cdcl-nli/arrange_hallucination_data.py文件中的下面代码进行模型调用
# 添加 CDCL-NLI 路径以使用 DM_RST 模块
sys.path.append("/mnt/nlp/yuanmengying/CDCL-NLI")
from data.DM_RST import RST_Tree, precess_rst_result
```
1. **获取 Token Spans：** 在分词时，通过 `return_offsets_mapping=True` 获取每个 Token 在原句中的 `(start, end)`。
2. **EDU 边界确定：** 根据 `EDU_Breaks` 提供的 Token 索引（例如 `[5, 10]`），取第 1 个 EDU 的起始 Token 的 `start` 和最后一个 Token 的 `end`，形成该 EDU 的字符范围。

### B. RST 树转图结构 (Tree to Graph)

DMRST 的输出如 `(1:Satellite=Contrast:4, 5:Nucleus=span:6)`，代表“EDU 1-4”通过 `Contrast` 关系修饰“EDU 5-6”。

* **代表节点法 (Head-Node Extraction)：** * 在 RST 理论中，Nucleus（核）是信息的中心。
* 我们建立从 Satellite 范围内的**每一个** EDU 指向 Nucleus 范围内**每一个** EDU 的有向边吗？**不，这样会导致图过于稠密。**
* **推荐做法：** 建立从 Satellite 组的每一个节点指向 该 Nucleus 范围内在原始成分树中层级最高（最靠近根部）的节点。边类型标记为 `Contrast`。

## 1.3 标签对齐 (Label Alignment) —— 核心逻辑

这是将人工标注（Span）转化为模型预测目标（Ground Truth）的过程。

### A. 数学判定公式

给定一个 EDU 节点 $E$（范围为 $[E_{start}, E_{end}]$）和一个人工标注的幻觉片段 $H$（范围为 $[H_{start}, H_{end}]$），判定 $E$ 是否为幻觉节点的公式为：$$Label(E) = \begin{cases} 1, & \text{if } \max(E_{start}, H_{start}) < \min(E_{end}, H_{end}) \\ 0, & \text{otherwise} \end{cases}$$

> **解释：** 只要 EDU 和幻觉 Span 之间存在正值的交集（即重叠），我们就认定该 EDU 承载了幻觉信息。

### B. 标签处理细节

1. **多片段覆盖：** 如果一个 EDU 覆盖了多个幻觉片段，或者一个幻觉片段跨越了多个 EDU，均按上述公式处理。通常一个长幻觉片段会激活连续的 2-3 个 EDU 节点。
2. **全局标签生成：**
$$Y_{global} = \bigvee_{i=1}^{N} Label(E_i)$$


即对所有摘要 EDU 的标签取 **“或”** 运算。只要有一个 EDU 被染红，整条样本就是幻觉样本。

## 🛠️ 数据处理伪代码实现

为了方便你理解，这里给出一个逻辑流程：

```python
def process_single_record(raw_text, labels, parser_output):
    """
    raw_text: 原始摘要文本
    labels: [{'start': 10, 'end': 25}, ...]
    parser_output: { 'edu_breaks': [5, 12], 'tree': '...' }
    """
    
    # 1. 映射 EDU 到字符级别
    # edu_char_ranges = [(0, 45), (46, 110), ...]
    edu_char_ranges = map_tokens_to_chars(raw_text, parser_output['edu_breaks'])
    
    # 2. 节点染色 (EDU Labeling)
    edu_labels = []
    for e_start, e_end in edu_char_ranges:
        is_hallu = 0
        for lb in labels:
            # 计算重叠
            if max(e_start, lb['start']) < min(e_end, lb['end']):
                is_hallu = 1
                break
        edu_labels.append(is_hallu)
    
    # 3. 树转边 (Tree to Edges)
    # 解析 (1:Sat=Rel:4, 5:Nuc=span:6)
    # 生成 edges = [[src, dst, rel_id], ...]
    graph_edges = parse_dmrst_tree(parser_output['tree'])
    
    return {
        "x_features": None, # 下一步通过 Encoder 提取
        "edge_index": graph_edges['index'],
        "edge_type": graph_edges['type'],
        "y_local": torch.tensor(edu_labels),
        "y_global": torch.tensor(1 if any(edu_labels) else 0)
    }

```

在第二阶段中，我们将“文本数据”正式转化为“拓扑图数据”。这一步的目标是让模型不仅能看到**语义（是什么）**，还能看到**结构（怎么组织的）**以及**证据（从哪来的）**。

## 2.1 节点特征提取 (Node Features) —— 多维向量融合

每个 EDU 节点不仅是一个语义向量，而是一个复合特征矩阵。我们将不同维度的信息拼接（Concatenate）成最终的初始向量 ：
$$\mathbf{x}_i = [\mathbf{v}_{sem} \parallel \mathbf{v}_{pos} \parallel \mathbf{v}_{ner} \parallel \mathbf{v}_{role} \parallel \mathbf{v}_{aligned}]$$
### 1. 语义特征 ($\mathbf{v}_{sem}$)

* **模型选择：** 建议使用 `modern-bert` 的隐藏层输出。 模型路径：/mnt/nlp/yuanmengying/nli2hallucination/models/modern-bert_large
* **提取方式：** 对每个 EDU 内的 Token 进行 **Mean Pooling**。
* **维度：** 通常为 1024 维。这部分捕捉的是该 EDU 的基础事实描述。

### 2. 相对位置编码 ($\mathbf{v}_{pos}$)

* **计算方法：** $Pos_{rel} = \frac{EDU\_index}{Total\_EDUs - 1}$（映射到 $[0, 1]$ ）。
* **必要性：** 摘要通常遵循特定的叙事顺序（如先结论后细节）。在判别幻觉时，位置信息能帮助模型识别“摘要开头是否偏离了原文主旨”。

### 3. 实体冲突标志 ($\mathbf{v}_{ner}$)

* **数据来源：** 基于 GLiNER 的提取结果。
* **优化逻辑（平滑化）：** 放弃传统的硬性 $0/1$ 判定，改为 实体差异分数 (Entity Discrepancy Score)。
- 计算方法： 对于摘要 EDU 中的实体 $E_{sum}$，计算其与原文实体库中语义最接近的实体 $E_{ctx}$ 的相似度。
- 特征值 $F_{dist}$： 若相似度 $\ge 0.95$（如“Hernandez” vs “Aaron Hernandez”），设为 $0$；若完全无匹配且相似度极低，设为 $1$。
* **作用：** 减少因 NER 模型提取误差或微小称呼变化导致的误报，精准探测 baseless_info（无依据信息）。
```python
from gliner import GLiNER
import torch
from difflib import SequenceMatcher # 用于计算字符串相似度实现平滑化

# 1. 初始化模型
model = GLiNER.from_pretrained("urchade/gliner_base-v2.1")

def get_smooth_ner_and_alignment_features(context_text, summary_text, summary_edus, threshold_tau=0.4):
    """
    context_text: 原始文档
    summary_text: 生成摘要
    summary_edus: 摘要 EDU 范围 [(start, end), ...]
    threshold_tau: 判定为“孤立节点”的相似度阈值
    """
    labels = ["person", "organization", "location", "date", "event", "number", "product"]
    
    # 2. 提取实体
    ctx_entities = model.predict_entities(context_text, labels, threshold=0.3)
    sum_entities = model.predict_entities(summary_text, labels, threshold=0.3)
    
    ctx_entity_texts = [e['text'].lower().strip() for e in ctx_entities]
    
    # 3. 计算每个摘要实体的“差异分数”
    # 优化点：引入实体差异分数 (Entity Discrepancy Score)
    sum_entity_scores = []
    for s_ent in sum_entities:
        s_text = s_ent['text'].lower().strip()
        
        # 计算该实体与原文所有实体的最高相似度
        max_sim = 0
        if ctx_entity_texts:
            max_sim = max([SequenceMatcher(None, s_text, c_text).ratio() for c_text in ctx_entity_texts])
        
        # 平滑化逻辑：相似度 >= 0.95 设为 0 (无冲突)；否则分数越高代表冲突越大
        discrepancy_score = 0.0 if max_sim >= 0.95 else (1.0 - max_sim)
        sum_entity_scores.append({
            'start': s_ent['start'],
            'end': s_ent['end'],
            'score': discrepancy_score
        })

    # 4. 映射到 EDU 节点并集成孤立节点标记
    edu_features = []
    
    for edu_start, edu_end in summary_edus:
        # A. 提取该 EDU 内的最高实体差异分
        edu_ner_score = 0.0
        relevant_scores = [s['score'] for s in sum_entity_scores 
                           if max(edu_start, s['start']) < min(edu_end, s['end'])]
        if relevant_scores:
            edu_ner_score = max(relevant_scores) # 取该 EDU 内最严重的冲突点
            
        # B. 孤立节点标记 (Is_Aligned Flag)
        # 逻辑：如果该 EDU 没有任何实体匹配且整体语义相似度极低(此处简化为基于实体的判定)
        # 在实际 RGAT 中，这一位应由 Cross-Alignment 阶段的最高 Cosine 分数决定
        is_isolated = 1.0 if edu_ner_score > (1.0 - threshold_tau) else 0.0
        
        edu_features.append([edu_ner_score, is_isolated])
        
    return torch.tensor(edu_features, dtype=torch.float)

# --- 使用示例 ---
context = "Aaron Hernandez was a former NFL star. He was engaged to Shayanna Jenkins."
summary = "Aaron Hernandez was a star. He dated the sister of his fiancée."
edus = [(0, 26), (27, 60)] # 假设的两个 EDU 范围

# 得到一个 (M, 2) 的特征矩阵：[实体差异分数, 孤立标记]
features = get_smooth_ner_and_alignment_features(context, summary, edus)
print(f"Node Features (NER Score | Isolated Flag): \n{features}")
```

### 4. RST 角色编码 ($\mathbf{v}_{role}$)

* **数据来源：** DMRST_Parser 输出的属性。
* **定义：** Nucleus（核心节点）记为 1，Satellite（修饰节点）记为 0。
* **逻辑：** 幻觉如果发生在 Nucleus 节点上，对全局质量的影响通常比 Satellite 节点更大。

### 5. 孤立节点标记 ($\mathbf{v}_{aligned}$)
* **定义：** 一个二进制位（Binary Flag）。
* **逻辑：** 如果摘要 EDU 在 2.2.2 跨图对齐 阶段未能建立任何有效边（所有相似度均低于阈值 $\tau$），该位设为 $1$。
* **作用：** 让 RGAT 显式识别出“证据孤岛”，这类节点是捏造事实（Baseless Info）的高度疑似区域。

## 2.2 边定义与拓扑构建 (Relational Edges)

为了实现 NLI 的“证据溯源”，我们将构建一个包含三类边的**异构关系图**：

### 1. 内部逻辑边 (Intra-RST Edges)

* **范围：** 分别在 Context 树内部和 Output 树内部连边。
* **方向性优化：**
  - 从属关系（Satellite-Nucleus） 保持单向边，从 Satellite 指向 Nucleus。
  - 并列关系（Nucleus-Nucleus）： 如 Joint 或 Sequence，必须建立双向边。
* **作用：** 保持文本内部的逻辑严密性。如果摘要内部的逻辑关系（如因果）与原文不符，RGAT 能捕获这种结构性不一致。

### 2. 跨图对齐边 (Cross-Alignment Edges) —— NLI 核心

* **逻辑：** 对于摘要中的每一个节点 ，去原文节点库 $\{C_1, C_2, ... C_n\}$  中寻找支撑证据。
* **构建策略：** 
* **计算亲和力：** $Score = \text{CosineSimilarity}(O_i, C_j)$。
* **Top-K 选取：** 为每个 $O_i$ 连接相似度最高的 $K$ 个原文节点（建议 $K=1 \sim 2$）。
* **动态剪枝：** 如果最高的相似度也低于阈值 $\tau$（如 0.4），则不建立对齐边，标记为“孤立节点”。


* **作用：** 这是模型判别“摘要这一句是否有依据”的物理路径。

### 3. 边类型映射表 (Edge Type Mapping)

为了输入 RGAT，我们需要将所有边映射为整数索引：
| 边分类 | 索引范围 | 示例 |
| :--- | :--- | :--- |
| **RST 关系** | 0 - 18 | `0: Attribution, 1: Background...` |
| **对齐关系** | 19 | `19: Evidence_Alignment` |

---

## 2.3 异构图的数学表示 (PyG 适配)

在 PyTorch Geometric 中，这一阶段的最终产物是一个 `HeteroData` 或带 `edge_type` 的 `Data` 对象：

- 节点向量 $X \in \mathbb{R}^{(N+M) \times D}$：合并 Context 和 Output 的所有节点。
- 邻接矩阵 $Edge\_Index \in \mathbb{R}^{2 \times E}$：包含所有内部边和跨图边。
- 边属性 $Edge\_Attr \in \mathbb{R}^{E}$：每个值对应一个关系 ID。

## 3️⃣ 第三阶段：模型架构 (Model Architecture)

模型采用 NLI 思想：**摘要中的每一个点都必须在原文中找到支撑。**

### 3.1 关系图注意力层 (RGAT Layers)

RGAT 的核心公式是根据边类型  来计算注意力：

$$e_{ij}^{(r)} = \text{LeakyReLU}\left(\vec{a}_r^T [W_r h_i || W_r h_j]\right)$$
$$\alpha_{ij}^{(r)} = \text{softmax}_j(e_{ij}^{(r)})$$

通过 2-3 层 RGAT，摘要节点会吸收到它所对齐的原文节点的语义信息。如果二者冲突，节点表征会产生“扭曲”。

### 3.2 跨图交互注意力 (Cross-Attention)

在 RGAT 之后，再接一层全量注意力，让 Output EDU 再次扫描 Context EDU。这能捕捉到 RGAT 拓扑结构之外的细微事实不一致。

### 3.3 双头输出 (Multi-Task Heads)

* **EDU 分类头：** * 输入：Output 的节点表征  $h_{out\_i}$。
* 输出：$P(\text{hallucination} | EDU_i)$。


* **全局分类头 (关键改进)：** * **Max-Pooling：** 取得分最高的那个 EDU 的概率作为全局概率。
* **逻辑：** 摘要就像一串链条，最弱的一环（有幻觉的那一句）决定了整体的成败。

---

## 4️⃣ 第四阶段：训练与评估细节

### 4.1 损失函数 (Loss Function)

为了平衡局部和全局，我们使用加权损失。同时针对幻觉样本稀缺的问题，引入 **Focal Loss**：
$$L = \lambda_{global} L_{BCE\_Global} + \lambda_{edu} \sum L_{Focal\_EDU}$$

> **Focal Loss** 会强制模型去关注那些“难以判定”的节点，而不是被大量的正常样本带跑。

### 4.2 训练技巧

* **硬样本挖掘 (Hard Negative Mining)：** 重点训练那些质量被标为 "bad" 但模型预测为 "good" 的样本。
* **Dropout：** 在 RGAT 层加入  的 Dropout，防止过拟合到特定的 RST 路径上。

### 4.3 评估指标

* **Global Level：** Precision, Recall, F1-score (重点看 F1 score)。
* **EDU Level：** * **Recall@K：** 前 K 个预测的幻觉 EDU 是否包含真实的幻觉。
* **IOU：** 预测的幻觉区间与人工标注区间的交并比。

# 🛠️ 基于 DMRST 格式的幻觉检测数据处理全流程

## 1️⃣ 第一阶段：DMRST 输出解析（Parsing & Mapping）

以一条记录（如 ID 276）为例，我们需要对 `Context` 和 `Output` 分别运行 Parser。

### 1.1 处理 EDU 边界与字符对齐

DMRST 输出的 `EDU_Breaks` 是 Token 索引。为了对齐 `hallucination_labels`（字符偏移量），我们需要：

1. **分词并记录位置：** 记录每个 Token 对应的原始字符 `(start_char, end_char)`。
2. **确定 EDU 范围：** 根据 `EDU_Breaks` [5, 10, ...]，将 Token 归组，计算出每个 EDU 的起始和结束字符位置。
> **结果：** 得到 `EDU_List = [{"id": 0, "text": "...", "start": 0, "end": 50}, ...]`



### 1.2 解析 `tree_parsing_output`（构建边）

DMRST 输出的格式如 `(1:Satellite=Contrast:4, 5:Nucleus=span:6)`。这是一种 **Constituency Parsing（成分句法）** 风格。我们需要将其转化为 **Dependency Parsing（依存句法）** 风格的图边。

**转换算法：**

* **识别核心（Nucleus）：** 在每一对关系中，`Nucleus` 是核心，`Satellite` 是修饰。
* **建边规则：** 建立从 `Satellite` 指向其对应 `Nucleus` 范围内**代表节点**的边。如果是 `Nucleus-Nucleus`（如 Joint），则建立双向边。
* **示例：** `(1:Satellite=Contrast:4, 5:Nucleus=span:6)` 表示 EDU 1~4 修饰 EDU 5~6。我们可以建立一条类型为 `Contrast` 的边，连接这两组节点的根部。

---

## 2️⃣ 第二阶段：标签构造（Label Generation）

我们需要利用 `hallucination_labels` 对 Output 端的 EDU 进行“染色”。

### 2.1 字符重叠判定

对于 Output 的每一个 EDU  $e_i$：

1. 提取人工标注的幻觉 Span $S = \{[start_1, end_1], [start_2, end_2], ...\}$。
2. **判定逻辑：** 如果   $e_i$ 与 $S$   中任何一个区间有交集，则该 EDU 节点的局部标签  $y_{edu\_i} = 1$。
3. **全局标签：** 如果整篇摘要中任何一个 $y_{edu\_i} = 1$，则 $y_{global} = 1$。

---

## 3️⃣ 第三阶段：跨图异构图构建（Heterogeneous Graph）

将 Context 的树和 Output 的树合成一个大图。

### 3.1 节点特征 (X)

* 使用模型自带的 `xlm-roberta-base` 最后一层隐状态，对每个 EDU 内的 Token 进行 **Mean Pooling**，得到节点向量。

### 3.2 边索引 (Edge Index)

* **类型 1 (Internal RST)：** 由 DMRST 解析出的内部修辞边。
* **类型 2 (Cross-Alignment)：** * 计算摘要节点 $O_i$  与所有原文节点 $C_j$ 的相似度。
* **建边：** 为每个 $O_i$  选出相似度 Top-1 的 $C_j$ 建立边。
* **作用：** 这模拟了 NLI 中的“前提-结论”对齐。

## 4️⃣ 第四阶段：模型输入示例 (Python / PyG)

假设一条数据经过处理后的结构如下：

### 1. 节点与标签

* **Context Nodes:** 10个 (ID: 0-9)
* **Output Nodes:** 4个 (ID: 10-13)
* **y_edu (局部标签):** `[0, 0, 1, 1]` (仅针对 ID 10-13)
* **y_global:** `1`

### 2. 边 (Edge Index & Attribute)

## 5️⃣ 优化后的训练方案总结 (Markdown)

# 📄 摘要幻觉检测：RST-RGAT 优化方案 (DMRST 适配版)

## 1. 数据构造逻辑

* **EDU 映射：** 将 DMRST 的 `EDU_Breaks` 映射回字符偏移，实现与 `hallucination_labels` 的精准对齐。
* **关系转化：** 将 DMRST 的层级括号输出转化为三类图边：`Intra-Context-RST`、`Intra-Output-RST`、`Cross-Alignment`。
* **节点表征：** 融合 XLM-RoBERTa 语义特征与位置编码。

## 2. 幻觉标签使用 (NLI 风格)

* **局部定位 (EDU Label)：** 每一个 Output EDU 都会预测一个幻觉概率。这解决了“幻觉在哪里”的问题。
* **全局判定 (Global Label)：** 对 Output 节点的局部预测值进行 **Max-Pooling**，作为整体摘要的幻觉判定。
* **无需分类：** 无论 `baseless_info` 还是 `conflict`，统一视为幻觉节点，简化任务复杂度，提升模型对“异常”信号的敏感度。

## 3. 模型预测目标

* **双重输出：** 1. `Global_Hallucination_Score` (0/1)
2. `EDU_Hallucination_Mask` (List of 0/1)
* **优势：** 相比纯文本判别，RGAT 能通过“对齐边”捕捉到原文中缺失的证据，通过“RST边”捕捉到摘要内部的逻辑断层。
